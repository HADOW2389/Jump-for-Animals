# Exlumiaa Hub — [Jump for Animals!]

Advanced automation and utility suite for **[Jump for Animals!]** on Roblox.

## Features

- **Auto Squat Train** + 2X Bonus
- **Auto Collect Eggs** (filter per area)
- **Auto Place on Plot**
- **OP Egg Tracker** + Auto TP
- **Guard Drop Block**
- **WalkSpeed / JumpPower** adjustments
- **TP To Home** (`Q` keybind)
- **Teleport to Area** (10 areas supported)
- **Server Hop**
